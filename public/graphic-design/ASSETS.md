# Graphic design portfolio assets

All portfolio artwork was supplied or approved by Whitney. This release includes holiday posters, full brochure spreads, two continuous phone longforms, safety communication, the office VI board, Jiangdong Cup materials, Minshengbao redesign comparisons and desktop wallpapers. Original artwork files remain unchanged.

- iPhone frame: [Shots iPhone 17 Pro](https://shots.so/mockups/iPhone%2017%20Pro/portrait/deep-blue.png), with its matching display mask.
- MacBook frame: [Shots MacBook Air M2 Midnight](https://shots.so/mockups/Macbook%20Air%20M2/portrait/midnight.png). Only transparent export margins were trimmed. Wallpaper uses centered cover fitting, with no added background strip; the menu bar and Dock overlay the original image. macOS application icon assets were exported from standard system application resources.
- Poster gallery scenes: [Mockups Design](https://mockups-design.com/poster-gallery-mockup/), original template views 1 and 4, flattened with the supplied original poster artwork. [License](https://mockups-design.com/license/). Editable templates are excluded.
- ASCII hero: [ASCII Magic Sphere to Cube Morph](https://www.ascii-magic.com/ascii/sphere-cube-morph), adapted with monochrome/purple character rendering. Vendored source retains its MIT notice in `vendor/ascii-magic/LICENSE`.
- VI board: original presentation header removed; all application artwork retained.
- App redesign: four old screenshots and seven supplied new UI designs. Personal identifiers in the old profile and payment previews are blurred in the derived images.

This folder contains production page assets only; local screenshots, scripts, verification artifacts and source documents are excluded.
